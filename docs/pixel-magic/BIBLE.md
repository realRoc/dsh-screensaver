# 《Pixel Magic》视觉圣经 · 草案 v0.2

> **适用范围：只管《Pixel Magic》系列**（目前只有魔法书斋 `themes/magic-tower`；以后这个系列的新场景、新主题也按它做）。
> 其他主题（亚空间、basic 等）不受这份文件约束。
> 现状评估见 [AUDIT.md](AUDIT.md)。数值是第一版目标，按第一个重构镜头的实测再调，调完就固定。

## 0. 总纲：画面为主体负责

**画面里的每一样东西，都要为主角和这一幕的情绪负责。**
它要么把视线引向主角，要么在讲这一幕的情绪；两样都不做的，就退到暗处当质感，不许抢戏。

这个系列有三种情绪，同一个主角：

| 幕 | 情绪 | 一句话 | 主角在做什么 |
|---|---|---|---|
| **书房**（待机） | **静之美** | 满屋子的魔法藏品都睡着了，只有月光和一盏烛火醒着，照着读书的骑士 | 月光下读书，偶尔翻页、抬头望月 |
| **爬塔**（有会话在跑） | **动之美** | 无尽盘旋的书阶，上升的骑士，光怪陆离的魔法围着他一起往上涌 | 一步一步匀速往上走 |
| **转场**（进塔 / 回书房） | **绚丽的过渡** | 静与动之间的一次爆发：从他读的那本书炸开，落进旋转的塔；回来时收拢进书页，归于安静 | 被卷进去 / 被送回来 |

反面教材（已经被否过的）：激昂的鼓点、刻意的「叮」光柱、运镜和推拉缩放、主角出画。

## 1. 共同的地基（三幕都一样）

### 1.1 主角永远是第一读物

- **位置**：书房身体中心在黄金分割点 (0.382, 0.618)；塔里复刻 11-18 那条视频——小（约画面高 13%）、在左 (0.29, 0.58)。先量后改，16:10 / 16:9 / 21:9 各测一次。
- **小而清楚**：塔里他只占 13% 高，所以「被看见」不能靠大小，只能靠这三样，缺一不可：
  1. **轮廓光**：主角身上有一道别人没有的冷色轮廓光（书房来自长窗，塔里来自天井 / 塔顶开口）；
  2. **身后压暗**：他身后半个身位的背景压在色阶 0–1 档，形成一圈「安静区」；
  3. **身边一盏暖光**：书房是书桌烛台，塔里是他的剑（辉石光）和最近的一盏灯。
- **特效不盖他**：任何粒子、光带、光柱都不从他身上穿过去；可以绕着他、跟着他、落在他脚边。
- **检查法**：截图缩到 64 px 宽（或眯眼），第一眼落在他身上。转场的爆发峰值那一下除外。

### 1.2 一条像素网格，动静细微不同

- **静的东西在美术网格上**：建筑、家具、道具、主角，按「骑士精灵一个像素对一格」定渲染行数，最近邻放大，不插值。书房 520 行，塔里 615 行（骑士在塔里小，同样的规则算出来行数多一点）。
- **动的东西可以细一倍**：粒子、光带、魔法阵、光柱在 **2 倍网格**（约 1040 行）上画，同样最近邻——比静物细一点、更灵，但仍然是像素。
- **光晕是唯一允许的「软」**：辉光（bloom）在全分辨率上叠，它本来就该是软的；它只给辉光色阶和火焰。
- 结果：静物颗粒统一、干净；特效闪闪发亮又不糊；两者一眼能分出「物」和「光」。

### 1.3 景深和颗粒：用像素自己的办法

- **不用景深模糊**（现在的移轴模糊）：像素糊了就不是像素画了。远近改用**空气透视**表达：越远越暗、越偏雾色（塔 `#183048`、书房 `#0e1828`）、细节越少（远处只剩剪影和色块）。
- **不用颗粒噪点**：在像素画里噪点读起来是脏。需要过渡的大块渐变（月光、光柱边缘）用**有序抖动**（4×4 Bayer），那是像素画自己的颗粒。
- **保留**：调色（暗部偏青、亮部偏金）、暗角。

### 1.4 调色板与材质

- **基准色阶**：骑士那 9 条（ink / steel / navy / gold / leather / crimson / page / glow / gem，每条 5 档，暗 → 亮，阴影偏蓝紫、高光偏暖）。场景材质从这里挑，或按同样规则新增一条（写进本文件）。材质名 `pal_<色阶>_<档>`。
- **物体的颜色守调色板**：建筑、家具、道具、主角只用色阶里的颜色。
- **魔法的颜色可以更野**：特效有自己的「魔法光谱」——随音高从紫 → 蓝 → 青 → 金（现在的 `PITCH_STOPS`），可以出现色阶外的颜色，但一次一族，不同时打翻调色盘。
- **金是引导线**：金色（地毯金边、扶手黄铜、烛台、书脊烫金）越靠近主角越亮，越远越暗、越接近暗金；画面里最亮的金在主角身上或手边。远处大面积的金（符文环、吊灯）压到暗金，除非它正在参与一个事件。

### 1.5 画法（按东西选表示方式）

源头永远是 Blender / 代码建模，不手画像素。

| 东西 | 表示 |
|---|---|
| 主角 | Blender 模型。**目标：带骨骼的网格 + 像素层**（4×4 采样投票、选择性描边、按色阶打光，规则同 `process_sprites.py`）；现阶段：精灵表。泼溅版（`#splat`）保留为实验，边缘偏软 |
| 家具、道具 | Blender 建模 → GLB 网格，色阶材质；关键道具可以进像素层拿描边 |
| 建筑 | 代码 / Blender 网格，像素贴图（32 px / 单位，贴图像素 ≈ 屏幕像素） |
| 特效 | 粒子 / 片面，画在 2 倍网格上；体积感的柔软东西（雾、烟、光团）可以用高斯泼溅 |

- **描边**：主角完整描边（外圈 + 内线），描边色是该部件自己色阶的最暗档（受光侧亮一档），不用纯黑；关键道具可选；建筑不描。

### 1.6 动画

- **连续插值**：主角和道具的动作在关键帧之间连续插值（骨骼），不按精灵表跳帧。
- **主角匀速、有分量**，步伐和《星井》的 3/4 拍对齐。
- **镜头**：不运镜、不推拉、不缩放；只跟随。呼吸 ≤ ±0.03 画面。高潮靠音乐、光之巨剑和特效，不靠镜头。转场里的镜头动作是转场的一部分，不算运镜。

## 2. 书房 · 静之美

**主角：月光下读书的骑士。** 满屋子的东西是好事——这是一间塞满魔法藏品的书斋，视觉上「满」是它的特色。**不减道具，管光。**

- **光只有两个来源**：
  1. **月光**（主光，冷）：从长窗斜进来，一束可见的体积光，窗格投影落在地上和骑士身上；
  2. **书桌烛台**（主角的暖光）：只照亮他、书和书桌一圈。
- **道具都「睡着」**：辉石、宝箱、水晶球、浑天仪核心、半身像的眼睛、剑的辉光槽，平时**不自发光**，只被月光和烛光照到；暗处的道具压在色阶 0–2 档，读起来是一层丰富的质感，而不是几十个光点。
- **蜡烛**：可以全部留着。离主角远的是**熄灭的蜡烛**（有烛泪、没火苗）或火苗压到辉光阈值以下；书桌一圈的才是亮的。
- **动只有慢的**：烛火摇曳、光束里的尘埃缓缓下落、翻页、呼吸、偶尔抬头望月。不放乱窜的粒子。
- **月亮是光源不是主角**：亮度高但面积和光晕受控，不能比骑士更抢眼；环绕月亮的光点和符文环压到几乎看不见。
- **它们会醒**：进塔转场时，睡着的道具一起亮起来（辉石涌动、宝箱开光、浑天仪转起来），这就是转场的「蓄力」（见 §4）。

**书房的量化目标**（无事件时）：独立亮点 ≤ 15、过曝 ≤ 1%、碎度 ≤ 4%（道具多，放宽一点；靠把暗处的对比压下去来降）。

## 3. 爬塔 · 动之美

**主角：上升的骑士。** 这里要光怪陆离、要动——但**乱和丰富的区别在于编排**。所有的动都要和「他在盘旋上升」这件事站在一起：

1. **方向统一：往上、跟着螺旋转。** 环境里的动态（尘埃、碎晶、飞书、粒子蛇、符文环、精灵）都沿塔的螺旋方向、顺着骑士前进的方向往上流动。乱窜、随机方向的东西改成跟螺旋走。画面要读出「整座塔在和他一起上升」。
2. **节奏统一：踩在拍子上。** 没有音乐时也有一个 3/4、♩=72 的内部节拍器：骑士的脚步、灯的明灭、事件的落点都对齐小节；大事件落在强拍。
3. **空间分层：天井是舞台，骑士身边是安静区。**
   - **天井（塔的中轴）**：大特效、浑天仪、光柱、巨剑、粒子蛇的主场，画面最热闹的地方；
   - **远处书墙**：缓慢的流光、扫光，压暗；
   - **骑士身边**：安静区，只有他自己的光（剑的辉光、脚步的辉光）和跟着他的东西。
4. **魔法光谱，一次一族**：特效可以色彩斑斓，但同一时刻以一族颜色为主（随音高 / 段落换），不是五色同时乱闪。
5. **亮点有主次**：可以很多，但要有层次——最亮的一级（辉光核心）留给当前事件和主角的剑；常驻的灯球、烛火、吊灯降一级，不进辉光核心。
6. **吊灯、符文环、浑天仪**：它们在天井里，正好在画面中心。平时是暗的剪影和暗金，参与事件时才亮起来；这样中心留给事件，不和骑士抢。

**塔的量化目标**：不限亮点个数，但
- 主角可读：骑士外接框里被特效覆盖的像素 ≤ 10%；他的局部对比在全画面排前 3（要骑士遮罩，`npm run style` 下一步加）；
- 无大事件时过曝 ≤ 3%；
- 大事件峰值不设限，但 1 秒内回落。

## 4. 转场 · 绚丽的过渡

**转场要炸、要绚丽。** 可以过曝、可以色散、可以满屏魔法阵——不设限，怎么好看怎么来。它只要做到一件事：**把一种情绪交给另一种情绪。**

### 进塔（静 → 动）

1. **蓄力**：书房里睡着的东西醒来——辉石涌动、蜡烛一齐亮起、浑天仪转起来、月光变强；镜头推向他读的那本书。
2. **爆发**：从书页炸开（书页、符文、光），落在 BGM 的第一波高潮上；这一下可以白、可以满屏。
3. **落地**：传送门的旋转方向 = 塔的螺旋方向，爆发收束时镜头已经在旋转的塔里、骑士已经在往上走——**动已经开始了**，不是从静止重新起步。

### 回书房（动 → 静）

1. **收拢**：塔里的流动减速，光往一本书里收（书飞到镜头前）；
2. **合书**：书页合上，光被收进书里；
3. **归静**：回到书房时，道具已经重新睡着，只剩月光和烛火——安静要「落下来」，最后 1 秒内不再有新的爆发。

### 转场的规则

- **母题连续**：书页、符文、月光的蓝、塔的金，在两边都出现，让两幕是一个世界。
- **一个手势**：转场从主角的书开始、到主角结束；中间可以很繁复，但起点和终点都落在他身上。
- **节奏**：爆发点对齐音乐（第一波高潮落在 BGM 的阻碍终止上）。
- **可访问性**：每秒闪烁不超过 3 次；开了「减弱动态效果」时，闪白和抖动减半。

## 5. 事件（会话怎么变成画面）

| 会话事件 | 画面 |
|---|---|
| 有会话开始 | 进塔转场（§4） |
| 塔里：时间流逝 | 常驻的编排动态（§3）+ 每 6–11 秒一个环境事件（剑 / 光柱 / 法阵 / 极光 / 脉冲 / 流星雨，两个大事件不相连），**落点量化到内部节拍器的强拍** |
| 某个会话完成 | 左侧法卷里金环闭合；场景里在骑士附近回应一个小的金色法阵 / 扶手流光（不打断环境事件） |
| 某个会话等待确认 | 法卷琥珀色呼吸；骑士的剑光跟着呼吸变暖 |
| 某个会话中断 | 法卷红色断环；场景里一次很短的暗红闪（不放大特效） |
| 全部结束 | 回书房转场（§4） |

（环境事件的间隔、事件池沿用 11-19 定下的；新增的是「量化到节拍」和「会话完成 / 等待 / 中断在场景里有小回应」。）

## 6. 风格检查（style lint）

`npm run style`（`themes/magic-tower/scripts/style.mjs`）录一圈关键帧 → 出表 → 不达标的标红，帧和 `report.json` 在 `scripts/out/style/`。改这个系列的画面，进 PR 前跑。

| 指标 | 含义 | 书房（静） | 塔（动） | 转场 |
|---|---|---|---|---|
| `lights` | 亮度 > 0.9、面积 ≥ 6 px 的独立亮点 | ≤ 15 | 只记录 | 只记录 |
| `hi%` | 亮度 > 0.85 的像素占比 | ≤ 1% | ≤ 3%（无大事件） | 只记录 |
| `edges%` | 强边缘像素占比（碎度） | ≤ 4% | 只记录 | 只记录 |
| `gold%` | 金色像素占比 | 只记录 | 只记录 | 只记录 |
| 主角覆盖 `cover%` | 骑士本人的像素里，被特效盖住的比例 | — | ≤ 10% | — |
| 主角对比排名 | 骑士外接框的局部对比，在不含光源（没有亮度 > 0.95 的像素）的同样大小格子里排第几。光源本身（月亮窗、烛台、灯球）可以比他亮——光就是照着他的 | 第 1 | 前 3 | — |

两项都有了：外接框来自 `magicTower.knightRect()`；覆盖率是同一时刻多画两张（`magicTower.setDebugView({ fx: false })` 藏掉特效、`{ knight: false }` 只藏骑士），骑士的像素里被特效改了颜色（> 28/255）的比例。骑士自己的光（剑上滴落的辉光）不算特效。

## 7. 生产流程（新场景 / 新镜头）

1. **情绪 + 一句话 + 主角在做什么**：这一幕是静、动还是转场；先出 1–3 张静帧（可以是 Blender 粗模截图），标出主角、安静区、热闹区。
2. **白模 + 构图**：灰模，只定主角位置、引导线（螺旋、栏杆、光束）指向主角。量主角位置。
3. **光**：静的幕只开主光 + 主角暖光；动的幕先定天井是舞台、主角身边是安静区。
4. **材质 + 道具**：道具尽情放；暗处的压暗，不自发光。
5. **动态和特效**：动的幕按 §3 编排方向、节奏、空间；转场按 §4 的三段。
6. **风格检查**：`npm run style` 达标。
7. **录视频审**：配《星井》录一段（`music/record.mjs`），用户看视频拍板。
